# leomanderr.github.io

Mi portafolio personal. Sitio estático, sin dependencias ni framework.

**En vivo:** https://leomanderr.github.io

## Qué hay acá

Tres automatizaciones que construí de punta a punta, con el resultado
medido de cada una:

- **Cierre operativo diario** — Python, tareas programadas. Elimina 45
  minutos diarios de planilla y corre solo todas las noches a las 23:30.
- **Asistente de atención al cliente con IA** — n8n, OpenAI API, RAG
  sobre Supabase/PostgreSQL, con memoria conversacional y escalado a
  una persona.
- **Conciliación bancaria automatizada** — n8n, Google Sheets,
  JavaScript. Baja una tarea de 3 horas a 15 minutos sobre 500
  movimientos.

El CV descargable también vive en este repo.

## Cómo está hecho

HTML y CSS escritos a mano en un solo archivo, sin build ni librerías
externas. Animaciones de aparición con IntersectionObserver, navegación
con resaltado de sección activa, y el CV embebido en la misma página.
Servido por GitHub Pages.
